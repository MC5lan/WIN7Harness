# 陌生仓库上手

目标：用最少的读取建立“可行动的地图”，不要一上来改文件。

1. **先看结构**：调用 `repo_map`；没有索引时用 `list_dir` 看顶层，再读 `README`、`AGENTS.md`、`go.mod` / `package.json` / `pyproject.toml` / `Cargo.toml` 中真实存在的文件。
2. **确认工具链**：用 `toolchain` 检查项目要求的语言版本与本机版本是否匹配；不匹配时先说明，不要直接改项目配置降级。
3. **找入口与测试**：定位 `main` / `cmd` / `src` / 路由 / 核心包；找到测试命令，先跑最小范围的构建或测试，记录基线是否本来就红。
4. **画地图**：用 5~8 条说明“入口在哪、核心模块怎么分层、数据怎么流、测试怎么跑、哪些目录不要碰”。
5. **写入项目记忆**：只把确认过的稳定事实用 `memory_save` 记录（构建命令、测试命令、坑），不要记录猜测。
6. **收尾**：给出下一步建议（读哪个文件、跑哪条命令、先修哪个问题），不要顺手改代码。

停止条件：已经能回答“改一个功能应该动哪几个文件、怎么验证”即可，不要为了完整而遍历整棵树。
