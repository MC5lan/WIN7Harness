# 单侧栏重设计（v1.40.1）

## 用户明确要求

1. 左侧那些看不懂的图标按钮不要散落；新建会话放在会话区；
2. 工作区与会话放在一起；
3. **全部会话、工作区放到「设置与工具」上方；取消原来独立的左侧部分**——
   也就是只保留一条侧栏，不再有「图标 rail + 会话侧栏」两层。
4. 现代化风格，参考 WorkBuddy：一条左侧栏，顶部新建任务，中间最近会话，
   底部导航与用户区；主区是干净的欢迎语、建议卡和大输入框。

## 最终结构

左侧只有一条 264px 的栏（其他页面正文统一从 264px 开始）：

```
┌────────────────────────┐
│ [logo] WIN7 Harness    │  顶部品牌
│        本地工作区       │
│ ┌────────────────────┐ │
│ │   + 新建会话        │ │  主按钮（会话区）
│ └────────────────────┘ │
│ [ 搜索标题或内容… ]     │
│ 最近                   │
│ ├ 会话 1               │
│ ├ 会话 2               │
│ └ …（滚动）             │
│ ──────────────────────  │
│ ★ 全部会话             │  底部导航，全部带文字
│ ▦ 工作区               │
│ ⚙ 设置与工具           │
│ v1.40.1 · 本地运行      │
└────────────────────────┘
```

## 代码变化

- `railPanelW`：56 → 176 → **264**（唯一侧栏宽度）。
- `app_layout.go`：`sideW / sideOcc / sideDrawer` 恒为 0，聊天区从 `railW` 开始；
  检查器（右侧）仍可独立抽屉化。
- `paintConvList`：画布起点改为 0，宽度用 `railW`；顶部补齐品牌区，
  新建会话改成整行主按钮，新增「最近」分组标题。
- `paintRail`：不再画独立图标栏；只画底部三项导航，并保证任何页面都能
  从侧栏回到会话/工作区/设置。非聊天页自动铺侧栏底色与顶部品牌。
- 设置页按用途重新分成 7 类：`模型与上下文`（接入、生成参数、全局指令、窗口预设）、
  `界面与体验`（主题、字号、交互、渲染）、`权限与安全`、`网络与更新`（代理、证书、自动更新）、
  `预算与成本`、`自动化`（自动验证、子任务并发、钩子）、`工具与关于`（工具面板、Git 身份、关于）。
  工作区按用户要求同时出现在侧栏底部和工具面板里。
- 设置页所有按钮重新梳理为明确动作：显示/隐藏密钥、拉取模型、选择模型、
  选择目录、打开目录、诊断连接、采用建议、打开自检与诊断、写入 Git 全局配置等。
- 点击「设置与工具」后左侧会话列表**不再消失**：所有页面共用同一份侧栏，
  在设置里点任意会话直接回到对话页。
- 所有二级页面统一页头（品牌 + 标题 + 一句说明 + 返回对话）；文字在按钮、
  导航项里按真实字体行高垂直居中，解决“框内文字偏上”。
- UI 回归脚本与 VM 压测脚本的坐标全部按新结构重算（设置入口在
  `侧栏底部 y=H-42`，工具页签在设置页顶部计算）。

## 稳定性结果

见 `docs/对标harness压测方案-v1.40.1.md`。重复矩阵曾抓到一次偶发失败
（dpi=1 第二轮 5/15，dpi=1.25 第二轮 14/15），已作为 flaky 记录并继续复跑确认。
