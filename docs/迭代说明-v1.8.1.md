# v1.8.1：内置模型预设全面更新（国产优先）

## 为什么改

v1.8.0 的预设还停在 deepseek-chat / gpt-4o-mini / qwen-plus / glm-4-plus 这一代，
用户第一次打开就得自己查模型名、手改地址，开箱即用的承诺打了折。
本次按当前主流型号重排预设，并把国产放在前面。

## 老配置怎么迁移

新增 `presetVersion`（当前为 2）。加载旧 config.json 时：

1. 按 ID 合并内置预设，老版本没有的新端点直接补进去；
2. 仍是内置地址的端点，刷新为新地址与新模型名；
3. 用户改过地址（自建网关 / 代理）的端点，地址与模型名原样保留，只补推荐列表；
4. API Key 一律不动；
5. 顶层 `model` 若还是旧名字（deepseek-chat、qwen-plus、glm-4-plus、gpt-4o 等），
   且当前端点仍是内置地址，则跟随新预设；否则不动。

`PresetVersion` 已是最新时不做任何改写，用户手填的模型名不会被悄悄换掉。

- 不支持视觉时的报错提示改为 glm-5.3-flash / qwen3.8-max / doubao-seed-2-1-pro / gpt-5.5；
- 新增 internal/core/config_preset_test.go：锁定预设完整性、旧配置升级、自定义端点不被覆盖。

## 升级建议

直接覆盖 EXE 即可，config.json 会自动迁移。如果你用的是公司自建网关，
地址和模型名会保持你原来填的；模型名已下线的，手动改成网关实际支持的型号。
