# v1.9.0：P0 五项基础能力（输入法定位 / 网络韧性 / 证书兜底 / 系统代理 / 单实例）

本版全部改动都不改变既有界面结构，只补三类"用久了才暴露"的底层缺口：输入法候选框位置、
模型接口偶发失败后的自动恢复、老 Win7 机器的证书与代理环境。零新增依赖，仍是单文件静态编译。

---

## 1. 中文输入法候选框跟随光标

**问题**：输入框是自绘的，Windows 不知道我们画的光标在哪，候选窗永远贴着窗口左上角或上一次
系统记录的位置。中文输入时眼睛要在两个地方来回跳。

**做法**：
- 新增 `internal/win32/ime.go`，用 IMM32 的 `ImmGetContext` / `ImmSetCompositionWindow`
  把组字窗口锚到光标位置。
- 窗口过程接管 `WM_IME_STARTCOMPOSITION`、`WM_IME_COMPOSITION`，在组字开始时同步一次位置。
- 新增 `CaretApp` 接口：绘制输入框时记录光标的屏幕坐标，IME 消息到达时向 App 取这个坐标。
  多行输入滚动后位置自动跟着变。

**验证**：输入长文本把光标拖到中间、换行、滚出可视区后再打中文，候选框均在光标下方 20px 处。

## 2. 429 / 5xx / 网络抖动自动重试退避

**问题**：以前只有超时，撞上限流（429）或 502/503 直接一次失败就抛给用户，得手动重发。

**做法**：
- 新增 `internal/llm/retry.go`：识别可重试状态码（408/425/429/500/502/503/504）与可重试网络
  错误（连接被拒、DNS 临时失败、EOF、超时），指数退避 + 随机抖动，尊重服务端 `Retry-After`。
- 默认最多 3 次，退避基数 800ms；400/422 这类请求本身的错误不重试，取消操作也不重试。
- 只在"还没往界面吐内容"的阶段重试：一旦模型开始流式输出，中断就不重试，避免文字重复。
- 网络错误给出中文可操作提示：证书类提示补 SHA-2 补丁 / 根证书，超时提示查代理防火墙。

**验证**：`internal/llm/retry_test.go` 覆盖重试次数、不重试场景、退避与 Retry-After、代理解析。

## 3. TLS 根证书兜底

**问题**：Win7 停止更新后根证书陈旧，访问新证书链的模型接口会 `x509: certificate signed by
unknown authority`，而用户往往不知道要补什么。

**做法**：
- 内置 22 张到 2026-11 之后仍有效的公共根证书（`internal/llm/ca_bundle.pem`），启动时与系统
  证书池合并，只在系统缺失时补位，不覆盖系统信任链。
- 支持在设置页指定"补充根证书"（企业自签根 / 内网代理根），也支持手动 PEM 文件。
- 极端排障场景可临时勾选"跳过证书校验"，界面明确标注风险，默认关闭。

## 4. 读取系统（WinINET）代理

**问题**：以前只认环境变量，而 Win7 用户几乎都是在"Internet 选项 → 连接 → 局域网设置"里配代理，
于是出现"浏览器能上、软件连不上"。

**做法**：
- 新增 `internal/win32/registry.go` 只读注册表，读 `ProxyEnable` / `ProxyServer` /
  `ProxyOverride`，支持 `http=`、`https=`、`socks=` 分协议写法与 `;` 分隔的绕过列表。
- 新增"网络"设置卡片：跟随系统 / 直连 / 手动三种模式，实时显示当前生效的代理来源（系统或环境
  变量），手动模式支持 `127.0.0.1:7890`、`socks=127.0.0.1:1080` 简写。

## 5. 单实例运行

**问题**：双击两次会开两个进程，同时写 `config.json` 与会话文件，可能互相覆盖。

**做法**：`CreateMutexW` 命名互斥量（按数据目录哈希命名，便携版放不同目录可各开一个）。
第二次启动时找到已有窗口并激活置前；找不到窗口就弹一句提示，不去抢写配置。

## 升级说明

- 直接覆盖 exe 即可，`config.json` 自动兼容，无需重配。
- 新增配置项均为可选：`proxy_mode`、`proxy_url`、`tls_extra_ca`、`tls_insecure`（默认跟随系统代理、
  不跳过校验）。
- 依赖仍为零：`CGO_ENABLED=0`，386 / amd64 双包，Win7 SP1 + KB2533623 + KB4474419。
