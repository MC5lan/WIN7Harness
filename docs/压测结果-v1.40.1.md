## 本轮抓到并修掉的问题

1. 页面断言假阳性：只检查 `Responding`，页面没切过去也算 PASS → 改为读 `harness.log` 的 `[page] xxx`。
2. DPI>1 下工具页坐标错误：设置页 `cw` 变小、卡片列数从 3 变 2 → 脚本按实际逻辑宽度重算。
3. 冷启动首次点击偶发丢失（386 更明显）→ 加最多 3 次重试并以页面名为准，重试次数写在报告里。
4. 「全部会话」消息数徽标文字贴顶：`0x21` 少了 `DT_VCENTER` → 改为 `0x25`。
5. 按钮/导航文字偏上：写死 `CY()-8` 未按字体行高居中 → 改用 `ui.TextTop`。
6. 点击「设置与工具」后左侧会话列表消失 → 所有页面共用同一份侧栏。
